ENGLISH IN ACTION — GitHub Pages starter

1. Create a NEW public GitHub repository (for example: english-in-action).
2. Upload the files from this ZIP to the repository ROOT, not the ZIP itself.
3. In Settings > Pages, select Deploy from a branch, main, / (root), Save.
4. Wait for the deployment to complete and open the published link.

This is a public DEMO site, not a protected paid-membership system. Do not put paid-only files in a public repository.

Add new games by uploading their HTML and any assets and adding entries in materials.js.
